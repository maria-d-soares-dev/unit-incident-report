# UNIT Extraterrestrial Incident Report

A fictional incident-reporting interface inspired by the UNIT
organisation from Doctor Who.

## Purpose

This project was created to practise HTML forms and native browser
validation.

## HTML concepts used

- Semantic HTML structure
- Forms
- Labels and inputs
- Fieldsets and legends
- Email, telephone and date fields
- Select menus
- Radio buttons
- Checkboxes
- Text areas
- Required fields
- Minimum and maximum character limits
- Submit and reset buttons

## Project status

This is the first HTML version of the project. Visual styling may be
added later with CSS.
